8. 우측 상단 계정명을 클릭하면 아래와 같은 정보를 확인할 수 있습니다.

{% hint style="info" %}
* 계정 ID : 해당 AWS 환경 전체를 식별하는 12자리의 고유 숫자로, 인프라 리소스의 소유권을 증명하는 '클라우드 주민등록번호' 같은 역할
* 계정 이름 : AWS 계정을 처음 가입할 때 설정한 대표 이름으로, 보통 결제 및 전체 관리를 담당하는 루트(Root) 소유자를 의미합니다.
* 계정 별칭 : 외우기 어려운 12자리 숫자 ID 대신, 직관적인 ID 사용을 위해 사용자가 직접 지정한 고유 영문/숫자 이름입니다.
* IAM 사용자 : 현재 콘솔에 로그인해 있는 주체로, 루트 계정으로부터 특정 업무(또는 실습) 권한만 제한적으로 부여받아 활동하는 실무자(서브 사용자)의 아이디입니다.
{% endhint %}
