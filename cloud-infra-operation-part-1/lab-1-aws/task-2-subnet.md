# Task 2 - Subnet

1. 좌측 메뉴 > 서브넷 > 서브넷 생성 클릭&#x20;

<figure><img src="../../.gitbook/assets/image (461).png" alt=""><figcaption></figcaption></figure>





2. 본인이 생성한 VPC를 선택&#x20;

{% hint style="warning" %}
다른 VPC를 선택하지 않게 주의
{% endhint %}

<figure><img src="../../.gitbook/assets/image (462).png" alt=""><figcaption></figcaption></figure>





3. 아래 설정에 따라 입력

* 서브넷 이름 : user\*\*-subnet-1
* 가용영역 : ap-northeast-2a 선택
* IPv4 CIDR 블록 : 10.0.1.0/24

<figure><img src="../../.gitbook/assets/image (463).png" alt="" width="486"><figcaption></figcaption></figure>



4. 새 서브넷 추가 클릭

<figure><img src="../../.gitbook/assets/image (464).png" alt="" width="202"><figcaption></figcaption></figure>





5. 아래 설정에 따라 입력 한뒤 하단 서브넷 생성 클릭

* 서브넷 이름 : user\*\*-subnet-2
* 가용영역 : ap-northeast-2c 선택
* IPv4 CIDR 블록 : 10.0.2.0/24

<figure><img src="../../.gitbook/assets/image (465).png" alt="" width="458"><figcaption></figcaption></figure>

<figure><img src="../../.gitbook/assets/image (466).png" alt="" width="289"><figcaption></figcaption></figure>





6. 좌측 서브넷을 클릭하면 전체 서브넷목록이 확인되는데, \
   필터링 검색창에 user\*\* 를 입력하여 본인이 생성한 서브넷 하단에 출력되게 설정

<figure><img src="../../.gitbook/assets/image (467).png" alt=""><figcaption></figcaption></figure>





7. 1번 서브넷을 선택하고 > 작업 > 서브넷 설정 편집 클릭

<figure><img src="../../.gitbook/assets/image (469).png" alt=""><figcaption></figcaption></figure>





8. 퍼블릭 IPv4 주소 자동 할당 활성화 옵션을 선택 한 뒤 저장 클릭
