# \[github] Task 1 - Repository Configuration (github 리포지토리 생성 및 Cloud9 구성)

실습 소개

github 을 통해 리포지토리를 생성해보고, 리포지토리와 연동 할 Cloud9 환경도 구성해봅니다.



1. &#x20;github.com 에 접속하여 가입 및 로그인



2. 우측상단 + 버튼 클릭, New repository 클릭

<div align="left" data-full-width="false"><figure><img src="../../../.gitbook/assets/image (725).png" alt="" width="353"><figcaption></figcaption></figure></div>



3. 이름란에 cicd\_web 을 입력하고 아래 Private 을 선택한뒤 최하단  Create repository 클릭

<div align="left"><figure><img src="../../../.gitbook/assets/image (726).png" alt=""><figcaption></figcaption></figure></div>

<figure><img src="../../../.gitbook/assets/image (727).png" alt=""><figcaption></figcaption></figure>



4. Cloud9 서비스로 이동 후 Create Environment 버튼 클릭

<div align="left"><figure><img src="../../../.gitbook/assets/image (662).png" alt="" width="563"><figcaption></figcaption></figure></div>



5. 아래와 같이 설정 후(나머지는 기본값) Create 버튼 클릭

Name : user##

Instance type : t3.small

Timeout : 1day
